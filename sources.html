1Subsea cables

Geometry, names, colors, owners, suppliers, length, ready-for-service year and landing points.

Source TeleGeography Submarine Cable Map API v3 License CC BY-SA — attribution required API unofficial / undocumented

Pulled from the TeleGeography Submarine Cable Map (submarinecablemap.com). The v3 endpoint is unofficial and undocumented; content is licensed CC BY-SA and requires attribution.

77 cables are retained — every system with at least one African landing point. These were filtered from roughly 1,400 cables worldwide via an Africa bounding-box prefilter, then a landing-country check to confirm an actual African landing.

Assumption

A cable is shown as planned when the API's is_planned flag is true or its rfs_year is later than 2026. TeleGeography flips is_planned to false as systems near ready-for-service, so the year check catches near-term systems that are not yet live.

3Terrestrial fiber

Backbone and metro fiber routes across the continent.

Source AfTerFibre (NSRC / Steve Song) License CC BY Method decoded vector tiles at build time

From the AfTerFibre project (afterfibre.opentelecomdata.org) — NSRC / Steve Song community data, CC BY. Geometry is decoded at build time from their MapLibre vector tiles via a z6 sweep over Africa.

144 operator-country aggregates, split by tier and status into 194 rendered features, containing 7,670 line segments across 41 countries.

Caveats
  • Freshness varies by country — this is community-contributed data.
  • Contributors digitize each route independently and the source is never topologically snapped, so links that physically meet often remain disconnected segments — a source-data limitation, not a tiling artifact (re-decoding at higher zoom yields the same routes and total length with finer vertices, but no additional connectors).
  • Segments are aggregated per operator + country + tier + status, so per-route detail is limited.
  • The app thins geometry in memory for render performance (Ramer–Douglas–Peucker, 0.04° ≈ 4 km tolerance, roughly −29% points). This is display-only; the data files are untouched.

4Terrestrial tiers (Core / Distribution / Access)

Network-role classification of terrestrial routes.

Source derived heuristically (not a source attribute) Confidence indicative only

Tier is not a source attribute; it is derived per route. The z6 tile sweep clips each physical route into many short fragments, so we first stitch fragments that share an endpoint back into connected routes (~2,205 of them), then classify each route by its geodesic length: ≥ 150 km → Core, 15–150 km → Distribution, < 15 km → Access. A backbone-optical source attribute (type/technology of DWDM, WDM, OPGW or OGW) forces Core over the length rule. The source carries no clean metro/access attribute, so nothing forces Access. This yields a genuine three-way split — roughly 32% / 28% / 40% Core / Distribution / Access by route (85 / 79 / 30 of the 194 rendered features) — replacing the old aggregate-length rule that put 124 of 144 aggregates in Core. Treat tiers as indicative only; per-feature overrides are possible via tier_overrides in data/annotations.js.

Access-tier coverage is sparse and uneven — a source-data limitation, not a classification artifact. ~93% of access-tier fragments sit in just three countries (Uganda 728, South Africa 375, Ghana 141 of 1,340) because AfTerFibre is a community-mapped backbone dataset: metro and last-mile fiber appears only where local contributors mapped it. The real metro/FTTx networks of most African cities (Lagos, Nairobi, Cairo, Abidjan…) are commercially sensitive and are not published in any open dataset, so their absence from the map does not mean they don't exist.

What the estimates lean on

  • TeleGeography price-erosion research: global floor $0.05–0.07/Mbps/mo at London / Marseille (Q2 2025); South Africa 10GigE −45% y/y; Johannesburg–London 100G wavelength median ~$46,900/mo (Q1 2024, −24%/yr); the Red Sea route near-flat due to the Egypt crossing bottleneck (Telecom Egypt fees reportedly up to ~$300M per cable).
  • Internet Society 2020 IXP report: Lagos IP transit $27.45/Mbps vs $0.43 for local peering.
  • Cloudflare bandwidth-cost series: historic Africa ≈ 14× the North America benchmark (2016-era, now outdated).
  • Cloud egress list prices: AWS Cape Town $0.154/GB (≈ 1.7× Europe); Azure South Africa $0.181/GB (≈ 2.1×).

6Fiber latency

Estimated typical round-trip time to US East, US West and Europe.

Type estimates Targets Ashburn · San Jose · Marseille Anchors 18 hand-calibrated hubs

Estimated typical RTT to US East (Ashburn), US West (San Jose) and Europe (Marseille, or London / Lisbon where noted). 18 hub cities are hand-calibrated anchors drawn from public measurement norms.

The other ~130 cities are computed as:

RTT ms = round5( haversine_km × 1.6 route inflation ÷ 102 km/ms × 1.2 overhead )

where 1.6 is a route-inflation factor, 102 km/ms is the speed of light in fiber, and 1.2 covers per-hop overhead. Real paths vary by provider, IXP presence and cable outages.

Note

Country-level values in the by-country table use the minimum RTT across that country's landing cities, and the winning city is labeled.

9Editability

What you can hand-edit, and how it survives regeneration.

Every estimate — capacity, egress rates, latencies, the Starlink model and tier overrides — lives in data/annotations.js. Edits there survive data regeneration. The data snapshot was generated 2026-07-28 (UTC); refresh it via the scripts in scripts/.
